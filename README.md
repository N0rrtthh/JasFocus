# ⏱️ JasFocus - Timer App

A beautiful, minimalist productivity timer app with iOS-style design, featuring automatic task progression, motivational messages, and satisfying completion animations.

## ✨ Features

- **🎯 Smart Timer** - Auto-progresses to next task when current task completes
- **💾 Data Persistence** - All tasks saved locally, survives browser restarts
- **🎨 Premium UI** - Glassmorphism effects, gradients, and smooth animations
- **🎉 Celebration Effects** - Confetti animation on task completion
- **💪 Motivational Messages** - Encouraging messages every 30 seconds during active tasks
- **📊 Progress Tracking** - Visual stats for completed tasks and time spent
- **📱 Responsive Design** - Works beautifully on all screen sizes
- **🎭 Bento Grid Layout** - Color-coded sections for better organization

# Build for production
npm run build
